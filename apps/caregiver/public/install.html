Add JustAsk to Chrome

JustAsk isn't in the Chrome Web Store yet. For now, you install it from this file. It takes about a minute, on the computer of the person you help.

Download JustAsk (.zip)
  1. Unzip the file. Right-click it and choose Extract All (Windows), or double-click it (Mac).
  2. Open Chrome's extensions page. Type chrome://extensions in the address bar and press Enter.
  3. Turn on Developer mode, using the switch at the top right.
  4. Click Load unpacked and pick the unzipped folder (the one with manifest.json inside).
  5. The “Set up JustAsk” page opens. Turn on JustAsk and the microphone, then type the 6-digit code from your helper page.

Tip: pin JustAsk with the puzzle-piece icon in Chrome's toolbar, so the button is always one click away.
