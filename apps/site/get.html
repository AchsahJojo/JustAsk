Get JustAsk

Ready in a few minutes.

Not in the Chrome Web Store yet. Build it once, then load it.

01 · Build

Copy, paste, run.

Needs Node 22.13 or newer.

git clone https://github.com/AchsahJojo/JustAsk.git
cd JustAsk
printf 'VITE_PLANNER_URL=https://avid-clam-982.convex.site\nVITE_CONVEX_URL=https://avid-clam-982.convex.cloud\n' > apps/extension/.env
npm install
npm run build:ext
02 · Load

Add it to Chrome.

Open chrome://extensions, switch on Developer mode, click Load unpacked, and pick:

apps/extension/.output/chrome-mv3
03 · Start

Turn it on. Just ask.

Allow the microphone, then press the button and speak.

Turn JustAsk onAllow microphone

Got a code from a helper? Type it in Settings.
