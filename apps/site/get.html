Get JustAsk

Load the extension into Chrome.

JustAsk isn’t in the Chrome Web Store yet, so you build it once and load it yourself. It takes a few minutes.

  1. Build it from the repository.

    The built folder isn’t checked in (.output is in .gitignore), so a fresh copy has nothing to load until you build it. You need Node 22.13 or newer.

    # get the code
git clone https://github.com/AchsahJojo/JustAsk.git
cd JustAsk

# point the build at the live JustAsk servers (public addresses, no keys)
printf 'VITE_PLANNER_URL=https://avid-clam-982.convex.site\nVITE_CONVEX_URL=https://avid-clam-982.convex.cloud\n' > apps/extension/.env

# install and build
npm install
npm run build:ext

    Skipping the .env line still builds, but that copy looks for a planner on your own computer and has no helper accounts.

  2. Load it in Chrome.

    Open chrome://extensions, turn on Developer mode (top right), click Load unpacked, and choose this folder:

    apps/extension/.output/chrome-mv3

  3. Turn JustAsk on.

    Press Turn JustAsk on, allow site access and the microphone when Chrome asks, then press the JustAsk button and say what you need.

  4. Have a code from a helper?

    Type it in JustAsk’s Settings. Your helper can then send you tasks and see when they’re done. JustAsk works without one too.
